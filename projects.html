Supermarket Analytics

A Power BI dashboard project built around supermarket transaction data.

Scope

The project uses a CSV dataset and a multi-page dashboard to explore business data.

Approach

Prepare data, define consistent measures and organize dashboard pages around business questions.

What this demonstrates

Dashboard construction, data preparation and visual communication.

Limitations and next steps

03

Python · Machine Learning · Evaluation

Machine Learning Study

Introductory experiments with supervised learning, model evaluation and overfitting.

Scope

Study exercises, not a validated production model or benchmark result.

Approach

Compare a baseline with a trained model and examine training versus validation performance.

What this demonstrates

Basic model evaluation and the importance of separating training from evaluation data.

Limitations and next steps

Record dataset, split strategy, seed, metrics and limitations.
